# 📝 To-Do List

A simple command-line To-Do List application built using Python.

## 📖 Description

This project allows users to manage daily tasks through a command-line interface. Users can add new tasks, view the task list, delete tasks by number, and exit the program.

## ✨ Features

- View task list
- Add new tasks
- Delete tasks by task number
- Input validation
- Simple command-line interface

## 🛠️ Technologies Used

- Python 3

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Run:

bash
python todo_list.py
